# Evergreen topic clusters (set Nov 28, 2026)

The only source for evergreen articles. Each run picks the first unchecked `[ ]` row of the highest-priority cluster that passes the source check and the duplicate check (editorial/DAILY.md). When a row is published, change it to `[x]` with the slug.

## Rules for every evergreen article
- Answers ONE question that no existing page answers. If an existing page covers it, update that page instead.
- Links UP to its cluster pillar (or the pillar's planned slug once it exists), and to at least 2 published siblings in the same cluster. Add a plain link back from the pillar and from one sibling (no dated note, no date change).
- At least one worked calculation, table or step-by-step method from primary sources. No generic explainer padding.
- Not a template: no reused section skeleton across articles in a cluster.
- Pillars are written first. A pillar is a hub: it summarises each sub-question in 2-4 sentences and links to the detailed article.
