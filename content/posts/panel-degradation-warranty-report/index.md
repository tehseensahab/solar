Most 25-year panel warranties still guarantee output based on degradation assumptions written a decade ago — roughly 0.5% annual loss. Some field studies report lower rates for newer monocrystalline panels; this page has not yet been rebuilt with those primary sources, so treat any lower figure as unverified.

This matters for payback calculations more than it sounds: the degradation rate you assume changes a 25-year output estimate, so check which rate a quote or calculator uses.
