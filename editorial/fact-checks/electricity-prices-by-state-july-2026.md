# Fact-check: electricity-prices-by-state-july-2026

Checked October 5, 2026.

- All prices: EIA Electric Power Monthly Table 5.6.A, July 2026 and July 2025, released Sept 24, 2026. Read directly from the EIA table page in the browser (same data as data/eia_prices.yaml).
- Calculations done in Python from the table: percent change, cents change, cost per 1,000 kWh, counts (44 up, 6 down, 13 states at 10% or more), rankings. DC excluded from state counts and rankings.
- US: 18.31 vs 17.45 = +0.86 cents, +4.93%.
- Hawaii/Louisiana ratio 48.00/12.72 = 3.77.
- NOT claimed: causes of any state's change. Article says EIA does not explain causes and links to state guides.
